# AI-Document-Reader
Using Python, MySQL and AI tools to read, store and answer some questions from the pdf.

Need to install Python, and two python libraries pypdf and anthropic(AI tool used here)

use these specific commands for various functions:

use <file_name>.py add #1.pdf #2.pdf ... to add the files

use <file_name>.py ask "Ques" or use <file_name>.py ask "Ques" --doc #2.pdf to ask a generic or specific question

or simply use <file_name>.py chat for multiple questions
